# 🛡️ Asafa Mahfuz Abiodun (Spencer) — Portfolio

Official portfolio site for **Asafa Mahfuz Abiodun (Spencer)** — NOC Intern at Galaxy Backbone, SOC Analyst, and Student Leader specializing in Blue Team defense, enterprise network monitoring, and security operations.

🌐 **Live Site:** [mahfuzasafa.com](https://mahfuzasafa.com)

---

## ⚡ Tech Stack

* **Framework:** React + TanStack Start (TypeScript)
* **Build Tool:** Vite
* **Styling:** Tailwind CSS + Shadcn UI
* **Icons:** Lucide React
* **Hosting & SSL:** Netlify + Let's Encrypt
* **Form Handler:** Formspree

---

## 🚀 Key Features

* **Responsive Design:** Optimized for mobile, tablet, and desktop viewports.
* **Security Operations Theme:** Custom terminal matrix and dark-mode aesthetic.
* **Interactive Contact Form:** Instant message delivery to Gmail via Formspree API.
* **Direct CV Download:** Integrated static resume download.
* **SEO Optimized:** Metadata, Open Graph tags, and custom favicon support.

## 🛠️ Local Development

Clone the repository and run the development server locally:

```bash
# Clone the repository
git clone [https://github.com/LifeWithSpencer/spencer-profile.git](https://github.com/LifeWithSpencer/spencer-profile.git)

# Navigate into the project directory
cd spencer-profile

# Install dependencies
bun install   # or npm install

# Start development server
bun dev       # or npm run dev
